## Deutsch

**Serial Monitor** ist ein plattformübergreifender Monitor für serielle Schnittstellen mit einer modernen grafischen Benutzeroberfläche.

### Was er kann
- **Ansichten**: Flexible Datenanzeige in HEX- und ASCII-Formaten.
- **Filter**: Unterstützung für reguläre Ausdrücke (Regex) und Datengrößenfilter.
- **Protokollierung**: Speichern von Logs in den Formaten BIN, HEX, ASCII und DEC.

### Verwendung

Einfacher Start - doppelklicken Sie einfach auf die Datei **`serial_monitor.exe`**!

## English

**Serial Monitor** is a cross-platform serial port monitor with a modern GUI.

### Features
- **Data View**: Flexible HEX and ASCII output display.
- **Filters**: Support for regex, data size, and intervals.
- **Logging**: Save logs in BIN, HEX, ASCII, and DEC formats.

### How to use

Basic run — simply double click the **`serial_monitor.exe`** file!

## Русский

**Serial Monitor** — это кроссплатформенный монитор последовательных портов с современным нативным GUI.

### Что он умеет
- **Отображение**: Гибкая настройка вывода трафика в форматах HEX и ASCII.
- **Фильтры**: Поддержка регулярных выражений (regex) и фильтрации по размеру пакетов.
- **Логирование**: Сохранение дампов в форматах BIN, HEX, ASCII и DEC.

### Как пользоваться

Быстрый запуск — просто запустите файл **`serial_monitor.exe`** двойным кликом!
